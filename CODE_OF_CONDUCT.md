# Code of Conduct

## Our Standard

Be respectful and constructive. This is a small, single-maintainer project — keep interactions low-friction:

- Critique code and ideas, not people
- Assume good intent; ask before assuming bad faith
- Keep discussions technical and on-topic

## Scope

Applies to the issue tracker, pull requests, and discussions in this repository.

## Enforcement

The maintainer may edit, lock, or remove comments and may ban participants who behave disrespectfully. Report problems by opening a private [security advisory](https://github.com/LarsArtmann/golangci-lint-auto-configure/security/advisories/new) or contacting the author directly.

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
