## e) WHAT WE SHOULD IMPROVE (process + tooling lessons)

1. **Assert configure's exit status in `sync_push_v3.sh`** before recording CONVERGED_AT_HEAD (grep the log for the banner; or check `Configure` result JSON). Kills the false-positive class permanently.
2. **Restore the config/fmt two-commit split in v3** — stage only the cfg file for commit 1, fmt residue for commit 2.
3. **Local lint gate is mandatory for feature commits on release days** — even at high load, `golangci-lint run ./pkg/linter/...` on the touched packages (the scoped run that worked for the repair commit) before push; CI-red-on-release-day is the worst possible ordering.
4. **Pre-filing enforcement check** — enumerate the target repo's `.github/workflows` (and issue-template config) for auto-close bots BEFORE drafting any upstream issue; fold into verify-before-filing as a step 0.
5. **Provenance rule for releases**: release artifacts must be built from the tagged commit. When a pre-publish gate forces a config fix, either include the fix before tagging (re-tag while unindexed) or cut a .0.1 with the fix — never build from a descendant commit as a standing practice.
6. **GHCR smoke should pull and run the image**, not just resolve a digest (one `docker run … --version` in post-release-verify or the backfill workflow itself).
7. **classify.py** — promote to a durable sweep tool (it already fixed the context-line bug); add a `--strict` mode that fails the batch on ANOMALY.
8. **Keep sweep state in one machine-readable ledger** — sync-results.tsv is close; add per-repo heal-recipe columns so the F73 KnownBadSettingsKeys decision reads from data instead of prose.
9. **Clean up credential-adjacent artifacts** after proofs (cosign.key with empty password in the cache dir).
10. **Record upstream repo renames** when pushes follow redirects (go-plugin-mvp → plugmarket) — stale paths bite the next sweep.
11. **Never re-derive the heal recipes** — the 15 recipes in the sweep report are the input for a future `RenamedLinterSettings` extension in `migrate`; reference, don't re-derive.
12. **Edit-tool discipline** — `view` before every edit on files touched by other agents/scripts (three collisions this session: sync_push.sh ×2, CHANGELOG ×1).
