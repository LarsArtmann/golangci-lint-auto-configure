## Summary

Successfully implemented auto-fix for empty version field that was causing golangci-lint v2 to reject configurations with `version: ""`.

## Problem

When running `golangci-lint-auto-configure configure` on a project with a golangci-lint config that has an empty version field (`version: ""`), the tool failed with:

```
Error: can't load config: unsupported version of the configuration: ""
```

golangci-lint v2 requires the `version: "2"` field in the configuration.

## Solution

Added a `preFixVersion()` function in `pkg/linter/fixer.go` that:

1. Detects if the version field is empty or not `"2"`
2. Sets it to `"2"` for golangci-lint v2 compatibility
3. Is called before `preFixDeprecatedLinters()` to ensure the config is valid before analysis
4. Logs the change for transparency
5. Saves the fixed config immediately so subsequent golangci-lint commands work
