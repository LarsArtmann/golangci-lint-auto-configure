## a) FULLY DONE (verified)

### The core discovery

golangci-lint **refuses to load** any config whose `run.go` targets a Go version newer than the one the binary was built with ("the Go language version (goX) used to build golangci-lint is lower than the targeted Go version"). This was verified empirically against golangci-lint v2.13.2 (built go1.27.1) with a scratch module before any code was written. Everything below flows from that constraint.
